About Unix Timestamps

Unix timestamp (also called Epoch time or POSIX time) is the number of seconds since January 1, 1970 at 00:00:00 UTC. It is used for:

  • Recording precise moments in time
  • Timestamping events in databases
  • API logging and monitoring
  • Cross-platform time tracking
  • System logging and debugging

Frequently Asked Questions

What is a Unix timestamp?

A Unix timestamp is the number of seconds elapsed since January 1, 1970 00:00:00 UTC (the Unix epoch). It is a timezone-independent way to represent a precise moment in time, used in databases, APIs, and system logs worldwide.

How do I get the current Unix timestamp in JavaScript?

Use Math.floor(Date.now() / 1000) for seconds, or Date.now() for milliseconds. Date.now() is the most reliable cross-browser method.

What is the difference between seconds and milliseconds timestamps?

Unix timestamps are traditionally in seconds (10 digits, e.g. 1715000000). JavaScript's Date.now() returns milliseconds (13 digits, e.g. 1715000000000). Many APIs expect seconds — divide by 1000 when sending from JavaScript.

What is the Year 2038 problem?

32-bit signed integers can only represent timestamps up to January 19, 2038. Systems storing timestamps in a 32-bit integer will overflow on that date. Modern systems use 64-bit integers, which won't overflow for billions of years.
